## 🚀 Quick Start

### Deploy on GitHub Pages

1. **Fork or Clone** this repository:
   ```bash
   git clone https://github.com/anshumaan-10/anshumaan-10.github.io.git
   cd anshumaan-10.github.io
   ```

2. **Customize** the content:
   - Update personal information in `index.html`
   - Modify social links and contact details
   - Add your own projects and achievements
   - Replace images in `/assests/` folder

3. **Deploy**:
   - Go to **Settings → Pages**
   - Source: **Deploy from branch**
   - Branch: `main` and folder `/ (root)`
   - Save and wait for deployment

4. **Visit** your live site at `https://your-username.github.io`

### Local Development

```bash
# Simply open index.html in your browser
# Or use a local server for better experience:

# Python
python -m http.server 8000

# Node.js
npx http-server

# VS Code
# Use Live Server extension
```

## ⚡ Performance Optimizations

This portfolio is blazing fast with **Lighthouse scores of 98-100**! Here's how:

### Key Optimizations
- **Service Worker Caching**: Repeat visits load in < 100ms
- **Async CSS/Font Loading**: Non-blocking render path
- **GZIP Compression**: 70% payload reduction via `.htaccess`
- **Resource Hints**: Preconnect to CDNs for faster DNS resolution
- **Critical CSS Inline**: Loader renders instantly before external CSS
- **Error Resilience**: Graceful degradation if CDN libraries fail
- **Lazy Loading**: Images and animations only load when in viewport


## 📝 Customization Guide

### Update Personal Info

Edit `index.html`:
```html
<!-- Line 9-11: SEO Meta -->
<title>Your Name | Your Title</title>
<meta name="description" content="Your description..." />

<!-- Line 596-598: Hero Name -->
<h1>Your Name</h1>

<!-- Line 613-617: Hero Description -->
<p class="hero-lead">Your bio...</p>
```

### Change Colors

Edit `styles.css` (lines 9-48):
```css
:root {
  --accent: #8b5cf6;  /* Change to your brand color */
  --cloud-blue: #4a9eff;
  /* ... more colors */
}
```

### Add Projects

Edit `index.html` in the projects section:
```html
<article class="card proj-card">
  <h3>Project Name</h3>
  <p>Description...</p>
  <a href="https://github.com/...">View on GitHub</a>
</article>
```
