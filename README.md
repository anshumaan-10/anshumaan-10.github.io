# Anshumaan Portfolio v11 (GitHub Pages)

This is a clean, FAANG-style portfolio landing page for **Anshumaan Singh**.

## Deploy on GitHub Pages
1. Create a repo (example): `anshumaan-10.github.io`
2. Upload these files to the repo root:
   - `index.html`
   - `styles.css`
   - `script.js`
3. Go to **Settings → Pages**
4. Source: **Deploy from branch**
5. Branch: `main` and folder `/ (root)`
6. Open your live site.

## Customize
- Update social links in `index.html`
- Add more projects and sections
